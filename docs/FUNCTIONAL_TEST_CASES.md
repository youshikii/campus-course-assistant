# 校园课程智能助手功能测试用例

最近执行结果见 [2026-11-08 功能测试执行记录](test-results/2026-11-08-functional-test.md)。下方结果栏用于记录下一轮手工测试。

## 测试准备

- 浏览器入口为 http://127.0.0.1:5173/login。使用管理员账号 M 和两个专用学生账号 A、B。建议给测试账号和数据加本轮唯一前缀，如 `ft-1108-01`。A 由注册用例创建，B 由管理员新增用例创建。
- 准备一门课程「测试数据库原理」，一条仅分配给 A 的周一课表，时间 08:00–09:40，地点 A101。有效期选两个相邻周一（例如 2026-11-09 至 2026-11-16）。测试前核对日期与星期。
- 准备 UTF-8 文本 `考核说明.txt`，内容为「数据库原理考核：期末考试 50%，课程实验 30%，平时作业 20%。本轮测试标识：蓝杉-7319。」另备一份有效 Markdown、一份空 TXT 和一份仅含普通文本但扩展名为 PDF 的损坏样本。
- 业务页面需 MySQL、后端与前端可用。课程助手还需 MCP 和聊天模型。个人资料的索引与问答另需 Chroma 和 Embedding。服务启动方式见[开发指南](DEVELOPMENT.md)。
- 按表格顺序执行，同一账号可复用前序数据。跨账号检查使用独立浏览器配置或先退出再登录。涉及删除和停服务的用例使用专用测试数据及隔离环境。
- 结果填写「通过 / 失败 / 阻塞 / 未执行」。失败或阻塞时记录实际结果、复现步骤和证据位置。
